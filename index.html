AgentMoss

Runtime Behavior Transparency & Long-Horizon Analysis for Autonomous Agents

Agent 运行时行为透明性与长时程分析方法

ICSE 2027 (under review) LLM Agent Runtime Monitoring Transparency

Abstract

As autonomous agents powered by large language models are increasingly deployed in software engineering tasks — from code generation to multi-step debugging — a fundamental problem remains: we cannot see what agents actually do at runtime. Existing evaluation frameworks focus on task-level success rates, but offer no lens into the internal decision trajectories, tool-use patterns, and failure cascades that determine real-world reliability.

AgentMoss introduces a runtime transparency framework that instruments agent execution with lightweight hooks — capturing fine-grained traces of reasoning, tool invocation, environment interaction, and state mutation — and projects them into a structured, queryable representation. We propose a set of transparency metrics grounded in information flow analysis, and demonstrate how long-horizon trace analysis reveals emergent failure modes invisible to conventional evaluation.

Contributions

  • Runtime hook instrumentation — a non-invasive adaptor-based tracing architecture (via httpx) that captures reasoning, tool calls, and environment state changes without modifying agent source code.
  • Structured trace representation — a unified trace schema that normalizes heterogeneous agent frameworks into comparable execution graphs.
  • Transparency metrics — quantitative measures of behavioral visibility, information flow, and decision consistency across long-horizon runs.
  • Empirical study — analysis of 5 popular agent frameworks over 200+ multi-turn tasks, identifying recurrent failure patterns and their trace-level signatures.

Architecture Overview
