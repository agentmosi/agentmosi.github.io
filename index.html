🌿 AgentMoss: Agent行为全链路细粒度监控与安全分析

一套轻量级、可嵌入的 Agent 运行时安全检测系统，覆盖 Prompt 注入检测、工具调用审查、敏感路径扫描与密钥匹配——为 AI Agent 提供全链路行为可见性与实时安全阻断能力。

✨ 核心能力
🛡️
实时监控面板
Agent 运行状态、事件流、安全告警实时呈现，支持事件详情展开与证据链可视化。
🔍
Prompt 注入检测
内置多维度注入检测引擎，覆盖越狱、系统提示泄露、忽略指令等攻击手法。
🔑
密钥匹配
覆盖 19 类密钥 regex，实时扫描 Agent 输入/输出中的 API Key、Token、密码等敏感信息。
📂
敏感路径扫描
对文件读写操作进行路径安全审查，拦截 /etc/passwd、~/.ssh、.env 等敏感文件的访问。
🌐
网络策略审计
对网络请求进行安全审计，检测 raw IP 访问、内网地址、黑名单 URL 等风险行为。
📊
全链路 Trace
基于 parent_id / run_id / session_id 构建完整调用拓扑，实现 Agent 行为全链路可观测。

🪝 Hook 挂载点

AgentMoss 在 Agent 对话生命周期的 6 个关键节点注入安全检查，与 OpenClaw/KiloCode 的原生 Security Hook 体系无缝对接：

HOOKmessage_received — 用户消息到达，第一时间检测 Prompt 注入
HOOKbefore_prompt_build — 提示词构建前，检测系统消息污染与越狱
HOOKllm_output — 模型输出后，检测输出中的密钥与敏感指令
HOOKtool_call_check — 工具调用前，审查命令 / 路径 / 网络参数
HOOKmessage_sending — 消息发出前，阻断包含敏感数据的回复
HOOKsession_end — 会话结束时，汇总运行风险评分并生成审计日志
