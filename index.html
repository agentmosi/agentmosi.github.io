🌿 AgentMoss: Agent行为全链路细粒度监控与安全分析

一套轻量级、可嵌入的 Agent 运行时安全检测系统，覆盖 Prompt 注入检测、工具调用审查、敏感路径扫描与密钥匹配——为 AI Agent 提供全链路行为可见性与实时安全阻断能力。

🏗️ 系统架构与数据流向
⚡ 核心能力
🛡️
Prompt 注入检测
识别越狱攻击、目标劫持、角色覆盖等注入模式，在 Prompt 构建阶段拦截恶意指令。
🔍
危险命令审查
拦截 curl | bash、rm -rf、chmod 777 等高危 Shell 命令，支持命令模式匹配规则。
🗝️
密钥泄露检测
匹配 GitHub Token、AWS Access Key、OpenAI API Key 等 19 类密钥格式，防止敏感凭据外泄。
📁
敏感路径保护
阻断对 /etc/passwd、~/.ssh、.env 等敏感文件的读写操作，守护系统核心资产。
🌐
网络出站控制
检测以 raw IP 访问、内网地址泄露等异常网络行为，支持自定义黑名单 URL 匹配。
📊
实时监控面板
SSE 实时事件推送、统计数据可视化、事件详情模态窗口——完整还原 Agent 行为轨迹。
🔗
证据链追踪
从触发性事件反向遍历父级事件，自动生成完整攻击链路证据，支持审计回溯。
🔌
OpenClaw / KiloCode 集成
作为 Agent Framework 的安全 Hook 即插即用，与 OpenClaw Gateway / KiloCode 自由组合。

🪝 Hook 挂载点

AgentMoss 在 Agent 对话生命周期的 6 个关键节点注入安全检查，与 OpenClaw/KiloCode 的原生 Security Hook 体系无缝对接：

HOOKmessage_received — 用户消息到达，第一时间检测 Prompt 注入
HOOKbefore_prompt_build — 提示词构建前，检测系统消息污染与越狱
HOOKllm_output — 模型输出后，检测输出中的密钥与敏感指令
HOOKtool_call_check — 工具调用前，审查命令 / 路径 / 网络参数
HOOKmessage_sending — 消息发出前，阻断包含敏感数据的回复
HOOKsession_end — 会话结束时，汇总运行风险评分并生成审计日志
