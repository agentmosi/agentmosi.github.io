Runtime Security Framework

AgentMonitor 框架概括

AgentMonitor 是面向 Agent Runtime 的旁路安全框架：在 OpenClaw、JiuWenClaw、Hermes 等运行时之外建立统一观测、策略判断、证据链和实时监控界面，不侵入主 agent 推理链路，却能在关键工具、消息和安装动作上完成阻断或审批。

打开实时监控
运行时旁路观测层Adapter 捕获 LLM 输入输出、工具调用、消息发送、子 Agent、安装流程。
↓ normalize
统一事件 IRAgentMonitorEvent 统一 run、session、agent、hook、payload、risk 与父事件。
↓ decide
策略引擎与证据链实时规则、本地低延迟判断、跨会话关联分析和 evidence graph。
↓ visualize
实时监控 UI风险事件、行为树、敏感数据流向、全局攻击链。
Adapter

多运行时接入

通过 OpenClaw 插件、JiuWenClaw hook、Hermes gateway 或其它 runtime adapter 接入事件，统一写入 /api/adapters/:runtime/events。

IR

统一事件语义

把不同运行时的 chat.tool_call、chat.final、工具结果与策略决策归一化，保留原始证据和父子关系。

Policy

低延迟策略面

对危险 shell、凭证读取、消息外发、子 Agent 任务和供应链安装做同步判定，支持 block、requireApproval、observe。

Recorder

持久化取证

事件流可落入 Memory、SQLite 或 JSONL recorder，支撑 run 列表、行为图、证据链和审计回放。

Correlation

跨会话关联

将侦察、敏感读取、暂存打包和外发阶段串联为攻击链，弥补单个 hook 只能看见局部动作的问题。

Dashboard

实时安全运营

页面 1 专注实时监控，页面 2 概括框架，页面 3 给出配置指南、核心数据结构和监控粒度。
