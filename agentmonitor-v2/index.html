Out-of-band Agent Security

AgentMonitor 架构与能力概览

AgentMonitor 是面向 OpenClaw / x-Agent 的旁路安全监控平面：在不改造 Agent 主运行时的前提下，通过插件 hook 捕获模型输入输出、工具调用、消息发送、子 Agent 生成和安装行为，并在关键路径执行实时阻断、审批与审计。

实时阻断

工具调用前安全检查

在 before_tool_call 阶段检测 rm -rf /、私钥访问、下载脚本执行等高危行为，返回 block 或 requireApproval。

数据泄漏

消息与会话防泄漏

在 message_sending 与 before_message_write 阶段拦截疑似 API key、token、private key 等凭证内容。

供应链

安装与子 Agent 防护

通过 before_install 和 subagent_spawning 防御恶意插件、skill 安装与子 Agent 凭证外传任务。

可观测性

全链路行为流

采集 LLM 输入输出、工具结果和策略决策，形成可检索事件、证据链和风险卡片。

轻量集成

独立插件入口

OpenClaw 只需配置 plugins.load.paths 指向 agentmonitor-demo/openclaw-plugin，无需修改 OpenClaw 源码。

本地优先

低延迟策略引擎

同步检查走本地规则引擎，不依赖远程 LLM，适合 80ms 级别的实时决策路径。

全局关联

跨会话攻击链发现

Recorder 持久化全量行为，再由 /api/global/findings 关联多会话中的侦察、读取、打包和外发阶段，发现单点 hook 看不到的攻击链。
