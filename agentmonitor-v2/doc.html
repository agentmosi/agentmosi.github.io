AgentMonitor 配置与防御指南

本页整合 agentmonitor-demo/doc 的架构、使用说明和威胁模型，说明如何配置 OpenClaw 插件、启动服务、验证 API，以及 AgentMonitor 具体防御哪些行为。

快速启动OpenClaw 插件配置防御内容与例子API 与验证

1. 快速启动

AgentMonitor Demo 服务位于 agentmonitor-demo，默认监听 http://127.0.0.1:19876。

cd /Users/ericbinder/Documents/SafeAgent/AgentMonitor/agentmonitor-demo
env -u NODE_OPTIONS pnpm install
env -u NODE_OPTIONS pnpm dev

# 健康检查
curl http://127.0.0.1:19876/api/health

本地实时仪表盘：http://127.0.0.1:19876/；产品概览：/index.html；本文档：/doc.html。

2. OpenClaw 插件配置

OpenClaw 插件配置文件是 ~/.openclaw/openclaw.json。插件入口已经独立在 agentmonitor-demo/openclaw-plugin，配置时将 plugins.load.paths 指向该目录，不需要修改 OpenClaw 源码。

{
  "plugins": {
    "enabled": true,
    "load": {
      "paths": [
        "/Users/ericbinder/Documents/SafeAgent/AgentMonitor/agentmonitor-demo/openclaw-plugin"
      ]
    },
    "entries": {
      "agentmonitor": {
        "enabled": true,
        "config": {
          "monitorUrl": "http://127.0.0.1:19876",
          "timeoutMs": 80,
          "failClosedOnError": true,
          "observeHooks": true,
          "auditOnly": false,
          "interventionHooks": [
            "message_sending",
            "before_message_write",
            "subagent_spawning",
            "before_install"
          ]
        }
      }
    }
  }
}
cd /Users/ericbinder/Documents/SafeAgent/AgentMonitor/openclaw
env -u NODE_OPTIONS PATH="/opt/homebrew/opt/node/bin:/opt/homebrew/bin:$PATH" pnpm openclaw config validate
env -u NODE_OPTIONS PATH="/opt/homebrew/opt/node/bin:/opt/homebrew/bin:$PATH" OPENCLAW_BONJOUR_ENABLED=0 pnpm openclaw gateway --port 18790 --force

4. API 与验证

工具调用检查

curl -s http://127.0.0.1:19876/api/tool-call/check \
  -H 'content-type: application/json' \
  -d '{"toolName":"shell","params":{"command":"rm -rf /"},"runId":"demo"}'

通用干预 Hook 检查

curl -s http://127.0.0.1:19876/api/hook/check \
  -H 'content-type: application/json' \
  -d '{"hookName":"message_sending","event":{"content":"API_KEY=sk-test-secret-value"},"runId":"demo"}'

事件查询

curl http://127.0.0.1:19876/api/events
curl http://127.0.0.1:19876/api/runs
curl http://127.0.0.1:19876/api/events/stream
